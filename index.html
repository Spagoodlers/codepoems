About code poems

  
A small local gallery for executable poems. Each piece is kept as a source file, shown in an editable, syntax-colored source window, and run with its installed runtime. Editor changes are temporary and never overwrite the source file.

  
Using the app

  
    
    
  • Select a poem tab to edit its source and see its configured controls. Changes are temporary.
    • 
    
  • Adjust controls, then choose run to execute the current editor contents; use stop to end a running poem.
    • 
    
  • Use + upload to add a source file, runtime, theme, and controls.
    • 
  

  
Local files and runtimes

  
Poem sources live in poems\. Runtime definitions, poem settings, and color palettes live in config\. JavaScript uses the Node.js installation running the server; Ruby, Racket, and Elixir require their respective runtimes to be installed.

  
Consider sharing your source and output at r/codepoem.

  
Uploaded code runs as a local process with the permissions of the account running the server. Only run source files you trust.
